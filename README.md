# KB Designs — Katlyn Brown Portfolio

A static portfolio for **Katlyn Brown**, instructional designer and content strategist.

## Pages

- `index.html` — selected work, resource library, approach, background, and contact details
- `case-study.html` — *From Content to Course* instructional-design case study

## Local preview

```bash
python3 -m http.server 3000
```

Open `http://localhost:3000`.

The site is dependency-free and GitHub Pages-ready. All visual assets, local fonts, project work, and downloadable documents are stored under the root-level `assets/` directory.
